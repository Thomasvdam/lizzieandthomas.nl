# Lizzie & Thomas

A simple, playful static site hosted on GitHub Pages at [lizzieandthomas.nl](https://lizzieandthomas.nl/). The site is plain HTML, CSS, and JavaScript; GitHub Pages serves `index.html` from the repository root. `CNAME` sets the custom domain.

To preview locally, run `python3 -m http.server 8000` and open `http://localhost:8000`. Run `./scripts/check` before publishing.
